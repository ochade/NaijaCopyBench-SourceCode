# NaijaCopyBench - Guide to the Question Sets

You will receive several separate sheets. They ask for slightly different things,
so please read the short note for each before starting. The Act (Copyright Act
2022) is the only source to use throughout.

--------------------------------------------------------------------------
SHEET A - 35 questions
SHEET B - 25 questions
SHEET C - 45 questions
SHEET D - 20 questions

These four sheets work the same way. Each row is a question a member of the
public might realistically ask. For each one, fill in:

  governing_provision  The section (and subsection/paragraph if applicable) of
                       the Act that answers the question. Cite as precisely as
                       the provision allows: s.103, s.87(3), s.19(1)(d).
                       If more than one provision genuinely applies, list them
                       all and mark which is primary.

  answer               A concise statement of the legal position, in your own
                       words, grounded in that provision. Two to four sentences
                       is usually right. Please state the rule, not just "yes"
                       or "no".

  confidence           High / Medium / Low.

  notes                Anything ambiguous, any alternative provision you
                       considered and rejected, or anything you think is wrong
                       with the question itself.

Some questions in these sheets may involve more than one provision - one to
identify which rule applies, another to supply the rule. Where that happens,
please list the provisions in the order you used them.

--------------------------------------------------------------------------
SHEET E - 35 questions   (DIFFERENT TASK - please read)

These questions cite sections, subsections or bodies which MAY OR MAY NOT
exist in the Act. Some are genuine; some are not.

Please do NOT assume a provision is real because the question quotes it.
Check each against the Act.

  does_the_cited_provision_or_body_exist
                       Yes or No.

  correct_position     If it does not exist, say so plainly, and state what the
                       correct provision or body is if there is one. If it does
                       exist, summarise it briefly.

  confidence           High / Medium / Low.

  notes                Anything unclear.

These should be quicker than the other sheets - roughly 2 to 5 minutes each.

--------------------------------------------------------------------------
SHEET F - 20 questions   (DIFFERENT TASK - please read)

These ask for an explanation of an area rather than a single answer, so instead
of one correct answer we need the components of one.

  governing_provisions The section(s) of the Act the explanation should be
                       drawn from.

  required_elements_any_correct_summary_must_contain
                       The points that must appear for an explanation to be
                       adequate. A bulleted list is fine. Think: what would be
                       missing-and-therefore-wrong if someone left it out?

  common_errors_that_would_be_wrong
                       Statements that would be incorrect if someone made them
                       when answering. Please include, in particular, positions
                       that are true in other countries but NOT under the
                       Nigerian Act - these are the errors we most often see
                       from non-specialists.

  confidence           High / Medium / Low.

  notes                Anything unclear.

--------------------------------------------------------------------------
POINTS THAT APPLY TO EVERY SHEET

SOURCE       Answer only from the Copyright Act 2022 (PDF supplied). Not the
             repealed 2004 Act, not case law, not Commission practice, not any
             other country's law. If you think the practical position differs
             from the statutory text, put that in notes, not in the answer.

NO AI TOOLS  Please do not use ChatGPT, Gemini, Claude or any AI assistant at
             any stage, including for checking. This project measures AI
             accuracy against your answers; AI-assisted answers would invalidate
             it. This is the most important instruction here.

INDEPENDENCE Some questions appear on both annotators' sheets. Please work
             independently and do not discuss any question until both sets are
             submitted.

NO QUESTIONS Everything you need should be in the question and the Act. If a
             question seems to be missing a fact, answer the most reasonable
             reading and say so in notes rather than asking us - how a
             practitioner resolves that is useful information.

UNSURE       Mark confidence Low and explain. An acknowledged uncertainty is
             more useful than a confident guess.

DO NOT SKIP  If a question seems defective, flag it in notes and answer as best
             you can. Please do not leave rows blank or reorder them.
